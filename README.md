# 小揚料理帖

原創台灣料理漫畫，繁體中文圖內對白，高壓縮 WebP 閱讀器。
第一、二集每集 12 頁、60 格；第三集為 60 格手機直式條漫，從上往下連續滑讀。

- [第一集：最後一桌熱飯](https://zuestrd20.github.io/xiaoyang-cooking-manga/)
- [第二集：脆響之前](https://zuestrd20.github.io/xiaoyang-cooking-manga/episode-2/)
- [第三集：湯裡的留白](https://zuestrd20.github.io/xiaoyang-cooking-manga/episode-3/)

第三集依螢幕高度保留逐格留白，提供閱讀位置選擇與完整劇情文字版。

所有人物與事件虛構，AI 生成圖像。漫畫不是完整食譜。



第四集《一起收口》：[線上閱讀](https://zuestrd20.github.io/xiaoyang-cooking-manga/episode-4/)。20 張高壓縮 WebP 切片、60 格連續直式閱讀，四集可互相切換。
